// about

From restaurant floors to server rooms.

I didn't start out in tech. For over a decade I worked in hospitality and logistics — managing restaurant operations in Moscow and Makhachkala, then coordinating deliveries in Germany. Those jobs taught me something engineering courses don't: how to stay calm when something breaks live, read a system end-to-end, and fix what's actually wrong instead of what looks wrong.

I kept circling back to computers — an HTML/CSS course in 2020, a Java web development program in 2022 — until in 2025 I made the full switch: 42 School, project-based, peer-reviewed, no shortcuts.

This website is a small proof of that: built, containerised and deployed by hand, as part of a larger Docker infrastructure project.
